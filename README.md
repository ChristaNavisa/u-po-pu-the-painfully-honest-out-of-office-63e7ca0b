One brutally honest out-of-office auto-reply for
[The Painfully Honest Out-of-Office](https://make.fun/bounty/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b)
on make.fun.

The entry is a single sentence, 57 characters:

> I am away until Monday; my inbox owes me 4,096 apologies.

It admits the one thing an employee only says in private — a 4,096-deep
unread inbox — while staying polite enough to survive being forwarded to a
manager. The reversal lands at the end: the inbox owes *me* the apologies.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
Deterministic: the same sentence on every run.
